# Бинарные материалы задания 3

- `colt.jar` — анализируемая библиотека Colt из материалов лабораторной №4.
- `concurrent.jar` — вспомогательная зависимость Colt, передаваемая SpotBugs через
  `auxclasspath`.

Файлы включены в проект, чтобы задание 3 запускалось после обычного клонирования
репозитория и не зависело от структуры родительских каталогов.
