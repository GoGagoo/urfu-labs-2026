# Лабораторная работа №5: Оценка качества ПО по ГОСТ 28195-89

## Описание
Программа рассчитывает фактор надежности программного обеспечения для класса прикладных программ для научных исследований (подкласс 503 по ОКП) в соответствии с ГОСТ 28195-89.

## Вариант 3
* Число отказов (Q): 7
* Число экспериментов (N): 1300
* Интервал времени восстановления (Тв): [0.6; 1.0] с
* Допустимое время восстановления (Тв_доп): 0.65 с
* Интервал времени преобразования (Тп): [10; 16] с
* Допустимое время преобразования (Тп_доп): 10 с
* Базовый критерий надежности: 0.90

## Как запустить
1. Убедитесь, что установлен Java Development Kit (JDK).
2. Откройте терминал в папке проекта.
3. Скомпилируйте файлы:
   ```bash
   javac Lab5/src/*.java
